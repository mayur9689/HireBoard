# HireBoard

A responsive frontend job portal built with **React and TypeScript** that allows users to discover, search, filter, sort, and view job opportunities through a clean and user-friendly interface.

## 🚀 Features

- 🔍 Search jobs by title, company, or skill
- 📍 Filter jobs by location
- 💼 Filter jobs by employment type
- ↕️ Sort job listings
- 📄 View detailed job information
- 🔐 Login and logout functionality
- 📑 Pagination for job listings
- ⚛️ Reusable React components
- 📱 Responsive user interface
- 🔷 TypeScript-based frontend architecture

## 🛠️ Tech Stack

- **React**
- **TypeScript**
- **JavaScript**
- **HTML5**
- **CSS3**
- **Vite**
